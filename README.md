# Blockchain Pseudonymity Not Anonymity

This Python script demonstrates the difference between pseudonymity and anonymity in blockchain transactions. It simulates generating a pseudonymous wallet address and several transactions on a public ledger. The example highlights how, despite using a pseudonym, all transactions associated with that address are publicly visible and linkable, which can eventually compromise true anonymity.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
